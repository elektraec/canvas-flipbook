# Logo de la Universidad Indoamérica

El visor usa `logo-indoamerica.png`, copiado del archivo proporcionado para este proyecto. Para actualizarlo, reemplaza ese archivo por otro PNG con fondo transparente y conserva el mismo nombre. Si prefieres SVG, cambia también la ruta de la imagen en `index.html`.

No incluyas el logo dentro de `pdf/`: esa carpeta está reservada para los documentos que abre el visor.
